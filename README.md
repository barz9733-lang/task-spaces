# משימות — מרחבי עבודה עם סוכן חכם

מערכת אישית לניהול משימות, בעברית מלאה ומימין לשמאל, עם סוכן AI מובנה שרץ בענן.
המשימות מחולקות **למרחבים** (בית, עבודה, לימודים, או כל מרחב שתיצרו), ולכל מרחב צבע ותצוגה משלו.

## מה יש בפנים

- **מרחבים**: שם, צבע ותצוגה לבחירה, אפשר להחליף תצוגה בכל רגע.
  - **קנבן**: חדשה / בעבודה / בהשהייה / הושלמה, גרירה בין עמודות, לחיצה על כרטיס פותחת עריכה מלאה.
  - **רשימת TODO**: וי לכל משימה (מעביר להושלמה), ממוינת לפי עדיפות: דחוף, גבוהה, בינונית, נמוכה.
  - **לוח שנה**: חודש שלם בסגנון גוגל קלנדר. לחיצה על יום פותחת משימה חדשה בתאריך הזה, גוררים משימות בין ימים.
- **משימה**: כותרת, תיאור, עדיפות (לכל אחת צבע קבוע בכל התצוגות), סטטוס, תאריך יעד.
- **דשבורד**: בוחרים אילו מרחבים להציג (הבחירה נשמרת במסד הנתונים), ורואים דחוף / להיום / באיחור, וכרטיס לכל מרחב: כמה פתוח, כמה באיחור וכמה נסגרו השבוע.
- **סוכן AI** (חלון צ'אט צף, כפתור בפינה הימנית התחתונה):
  - עובד על **סביבת עבודה** אחת בכל הודעה: מרחב ספציפי (נבחר אוטומטית כשנמצאים בתוכו) או כל המרחבים (בדשבורד). אפשר לשנות בקליק, והשרת אוכף את ההגבלה.
  - חמישה כלים: קריאה, הוספה, עדכון, מחיקה וסיכום משימות.
  - **אישור לפני פעולות רחבות**: מחיקה, או פעולה על יותר מ-3 משימות, מציגות כרטיס עם כפתורי "מאשר" / "לא מאשר". דבר לא קורה לפני אישור.
  - המסך מתעדכן מיד אחרי כל פעולה, והסוכן עונה בעברית קצרה.
- **כניסה** עם סיסמה אחת. מצב כהה / בהיר. מותאם למובייל.

## טכנולוגיות

Next.js 15 (App Router) · React 19 · TypeScript · Postgres (Neon) דרך `@neondatabase/serverless` · `@dnd-kit` לגרירה · OpenAI Responses API (`gpt-6-luna`) · CSS ללא ספריות.

## משתני סביבה

| משתנה | תיאור |
| --- | --- |
| `DATABASE_URL` | מחרוזת חיבור ל-Postgres |
| `OPENAI_API_KEY` | מפתח OpenAI |
| `OPENAI_MODEL` | לא חובה. ברירת מחדל: `gpt-6-luna` |
| `APP_PASSWORD` | הסיסמה לכניסה למערכת |
| `SESSION_SECRET` | לא חובה אבל מומלץ: מחרוזת אקראית לחתימת עוגיית הכניסה (אחרת נגזר מהסיסמה) |

ראו `.env.example`. מקומית שומרים אותם ב-`.env.local`.

## הרצה מקומית

```bash
npm install
npm run db:seed     # יוצר טבלאות ומכניס נתוני דוגמה (רק אם המסד ריק)
npm run dev
```

פקודות נוספות: `npm run db:setup` (טבלאות בלבד), `npm run db:reset` (מוחק הכל ומכניס נתוני דוגמה מחדש).

## פריסה ל-Vercel

1. מחברים את הריפו לפרויקט ב-Vercel.
2. מגדירים את משתני הסביבה למעלה (Production).
3. מריצים פעם אחת `npm run db:seed` מול מסד הנתונים כדי ליצור את הטבלאות.

## איך הסוכן בנוי

`src/lib/agent/` — `tools.ts` מגדיר את חמשת הכלים (סכמות strict) ואת הלוגיקה שלהם, `run.ts` מנהל את הלולאה מול המודל ואת מנגנון האישור:
כלי כותב מחושב קודם כ"פעולה" (כמה משימות ישתנו, אילו). אם צריך אישור, הפעולה נשמרת בטבלת `agent_pending` והלקוח מקבל כרטיס אישור. רק אחרי אישור (`/api/agent/confirm`) היא מתבצעת, והמודל מקבל את התוצאה ומסכם. התשובות מגיעות בסטרימינג (NDJSON) כדי להציג התקדמות.
